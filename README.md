# پیمان الکترونیک

فروشگاه آنلاین کالای دیجیتال (موبایل، لپ‌تاپ، صوتی، پوشیدنی، لوازم جانبی) و قطعات و ابزار الکترونیک (برد توسعه، سنسور، قطعات پسیو، ابزار).

ساخته‌شده با Next.js 16 (App Router، Cache Components)، React 19، TypeScript و Tailwind CSS 4. رابط کاربری کاملاً فارسی و راست‌به‌چپ است.

## اجرا

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # بیلد production
npm run start    # اجرای بیلد
npm run lint
```

برای production، نشانی دامنه را در `.env.local` تنظیم کنید (نمونه در `.env.example`):

```
NEXT_PUBLIC_SITE_URL=https://your-domain.ir
```

## ساختار

| مسیر | محتوا |
|---|---|
| `src/data/categories.ts` | دسته‌بندی‌ها و متن معرفی هر دسته |
| `src/data/products.ts` | محصولات نمونه: قیمت (تومان)، موجودی، مشخصات فنی |
| `src/lib/site.ts` | نام فروشگاه، تلفن، شهر، آستانه ارسال رایگان و هزینه ارسال |
| `src/lib/catalog.ts` | لایه خواندن داده (با `"use cache"`)؛ برای اتصال به دیتابیس فقط همین فایل عوض می‌شود |
| `src/lib/cart-store.ts` | سبد خرید سمت مرورگر (localStorage) |
| `src/app/` | صفحه‌ها: خانه، دسته، محصول، جستجو، سبد خرید، تکمیل خرید، sitemap و robots |
| `src/components/` | کامپوننت‌های مشترک |
| `.claude/skills/` | اسکیل‌های Claude Code برای طراحی، React/Next.js و SEO فروشگاهی |

## پیش از راه‌اندازی عمومی

این موارد هنوز نمونه یا جای‌نگهدار هستند و باید با اطلاعات واقعی جایگزین شوند:

- قیمت‌ها و موجودی محصولات در `src/data/products.ts`
- تلفن، شهر، آستانه ارسال رایگان و هزینه ارسال در `src/lib/site.ts`
- سیاست‌های نمایش‌داده‌شده در سایت: ضمانت اصالت، هفت روز مهلت بازگشت، ارسال رایگان
- تصویر محصولات: فعلاً به‌جای عکس، آیکون دسته روی زمینه کاغذ شطرنجی یا برد سوراخ‌دار نمایش داده می‌شود

## گام‌های بعدی

- درگاه پرداخت (مثلاً زرین‌پال) و فرم ثبت سفارش
- پایگاه داده و پنل مدیریت محصولات و سفارش‌ها
- عکس واقعی محصولات با `next/image`
- ورود کاربران با شماره موبایل و کد یک‌بار مصرف
- نماد اعتماد الکترونیکی (اینماد)
